# Curso AI Engineering

Ejercicios y notebooks del curso.

## Estructura

```
ejercicios/          # Scripts .py, una carpeta por tema
  01_asyncio/        # Concurrencia con asyncio (simular llamadas a LLMs)
notebooks/           # Notebooks .ipynb para explorar
```

Cada tema nuevo va en `ejercicios/NN_tema/`, con el número siguiente.

## Uso

```bash
uv run ejercicios/01_asyncio/simulacion_llamadas.py   # ejecutar un ejercicio
uv add <libreria>                                      # instalar dependencias
```
